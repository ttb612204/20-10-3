# 20-10-3

Website quà tặng tình yêu Ngày Phụ Nữ Việt Nam 20/10 dành riêng cho **tvy** ❤️.

### 🌟 Tính năng chính:
- **Khóa Trái Tim Sinh Trắc Học**: Quét dấu vân tay lồng trái tim mở quà độc quyền.
- **Dải Ngân Hà 3D Kỷ Niệm**: Tự do kéo xoay 360 độ khám phá vũ trụ tình yêu.
- **Quả Cầu Kỷ Niệm 3D**: Hội tụ toàn bộ hình ảnh kỷ niệm thành khối cầu xoay sống động.
- **Thiệp & Thư Tình Chân Thành**: Hiệu ứng mở phong thư và bức thư tình cảm xúc.
- **Bảo Mật Hình Ảnh**: Hình ảnh cá nhân được lưu trữ bảo mật qua CDN trực tuyến, không lưu trữ tệp ảnh nhạy cảm trong Git repository.
